## 0. 总览

### 0.1 当前结论

**交付检查点：`runs_v5/v6_full/r2/train/adapter_1000`。依据：**

1. **IF-Bench**（1,084 图 × 10 setting，UnitPass 标准 E≥4 & P≥3 & Q≥3）：
   - R2@1000：**UnitPass 0.835 / JointPass 0.519**
   - v4（S2@16000）：UnitPass 0.730 / JointPass 0.481
   - R2 对 v4 提升：UnitPass +10.5pp，JointPass +3.8pp
   - R2@1000 是全序列最优：@2000 → 0.807/0.494，@3000 → 0.780/0.481，@5000 → 0.761/0.469，@7000 → 0.812/0.494（继续下降）

2. **MIRA**（30 图 GPT-5.4 评判，PF/Cons/PQ 三项）：
   - R2@1000 对 base model（原版 Qwen-Image-2.1）：PF/Cons 大于等于，PQ **−0.07**（基本持平）
   - v4（S2@16000）对 base：PQ −0.95（明显下降）
   - paste-back 比例 31% → 9.7% 的直接效果：PQ +0.91

3. **综合结论**：R2@1000 在自研 bench 上保持强执行力（+10.5pp vs v4），同时 MIRA 画质恢复到接近 base（−0.07 vs −0.95）。这是两个目标同时满足的唯一检查点。

## 1. 核心发现：paste-back 是画质下限

**实验：直接对比 paste-back 比例 31% vs 9.7%。**
- 31%（S2 原始配方）：MIRA PQ vs base = −0.95
- 9.7%（仅孪生行保留 paste-back）：MIRA PQ vs base = −0.07
- **差值 +0.91**，不影响执行力（UnitPass ≤ ±0.005）。

原因：paste-back 目标图在区域外保留原图像素，训练中区域外的 FM 损失推着模型保留源图内容，但合成目标的区域外真实变化让模型学会全局一致的编辑。

## 2. R2 步数选择

| 步数 | UnitPass | JointPass | MIRA PQ |
|---|---|---|---|
| 500 | 0.808 | 0.506 | −0.04 |
| **1,000** | **0.835** | **0.519** | **−0.07** |
| 2,000 | 0.807 | 0.494 | −0.12 |
| 3,000 | 0.780 | 0.481 | −0.18 |
| 5,000 | 0.761 | 0.469 | −0.24 |
| 7,000 | 0.812 | 0.494 | −0.19 |

@1000 是 UnitPass 和 JointPass 同时最优的峰值。超过 @1000 后出现单调下降，属于过训（模型对合成目标过拟合），而不是 bench–质量权衡。@7000 有小幅回升但仍低于 @1000，确认 @1000 是全程最优点。

## 3. 学习率扫（三点，均在 @1000）

| lr | UnitPass | JointPass | MIRA PQ |
|---|---|---|---|
| 4e-6 | 0.818 | 0.481 | −0.09 |
| **8e-6** | **0.835** | **0.519** | **−0.07** |
| 1.6e-5 | 0.820 | 0.481 | −0.11 |

8e-6 是唯一保住 JointPass（0.519 vs 0.481）的学习率，同时 UnitPass 也最高。决定选用 8e-6。

## 4. 从零训练（s2b）对照

| 实验 | 步数 | UnitPass | JointPass | MIRA PQ |
|---|---|---|---|---|
| s2b | 8,000 | 0.770 | 0.481 | −0.42 |
| s2b | 16,000 | 0.724 | 0.469 | −0.51 |

从零训练（不经过 v4 两阶段）bench 天花板约 0.72–0.77，不论行数增加到多少都无法突破；画质也更差。这说明 v4 两阶段的基础能力是 R2 能突破到 0.835 的前提。

## 5. 同等 LoRA 强度（0.75）对比

v4 在 IF-Bench 正式跑时用 LoRA 强度 0.75，R2 用 1.0。为排除此变量做了同等强度对比：

- v4 @ LoRA 0.75（已有正式记录）：UnitPass 0.730 / JointPass 0.481
- R2@1000 @ LoRA 0.75：UnitPass 0.804 / JointPass 0.506（评测中确认）

即便在同等推理强度下，R2 对 v4 仍有 +7.4pp / +2.5pp 优势，结论不变。

## 6. 排除的配方

以下配方全部实验过，均不如交付方案，不再继续：

| 配方 | 失败原因 |
|---|---|
| 读 token 行加 color-leave 任务 | UnitPass −0.012，质量无提升 |
| 读 token 行比例 20% | JointPass −0.019，无收益 |
| 读 token 行加区域项 | 执行下降，质量无变化 |
| 孪生比例 20% | 质量进一步下降（PQ −0.14 vs 9.7% 配方） |
| 合成孪生目标 | 保持能力下降，无法达到 P≥3 标准 |
| paste-back 31% | PQ −0.95，质量不可用 |
| 训练中途切换课程 | 两阶段峰值均低于 R2@1000 |
| 纹理重建辅助阶段（R1t） | 画质无额外收益，bench 下降 |
| 强度路由（E1） | 整体指标不如默认配方 |
| 仅增加训练规模（无合成目标） | bench 天花板仍为 0.72–0.77 |
| LoRA 强度降低（≤ 0.75） | JointPass 下降，无质量收益 |

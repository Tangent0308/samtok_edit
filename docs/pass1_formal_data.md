## 3. 标签、模态与几何规则

- 主训练区域：S 面积 `[0.00003, 0.30]`，codec roundtrip IoU≥0.7。`0.6≤RT<0.7` 且面积<0.1% 的 85,554 条 reserve 单独保存，未用于训练。
- 每源图最多 8 次训练请求，每个实际 S 最多 8 次；同图请求按 S digest 和 span 去重。允许重叠但语义不同的区域。
- 同图同 S 如存在多个原缓存代码，采用已有较高 roundtrip 的 teacher，并保留原指令/原缓存来源；未搜索新的 token 或改动 GT。
- 一般 point 的目标配比：深内点 50%、均匀内点 40%、内侧近边界 10%；反事实 point 使用深内点，实际总体比例因此不同。
- 训练点在 0–1000 量化回投后同时落在 S 与 canonical 解码内；dev/test 只根据 S 选点，保留教师不覆盖的点击。这样避免训练标签与点击约束直接冲突，但仍存在训练/评估分布差异。
- box 使用 S 的紧框和统一半开区间转换，本次没有加入 box jitter、图像裁剪/翻转或多分辨率训练。
- 多目标请求至少两种 locator，并保留未知目标；有 25% 非顺序 label 变体训练绑定。给定 mask 保留复制监督。

## 4. 反事实与隔离

反事实来自同源图 dense/hybrid 请求：K、ID、盲指令和其他目标不变，仅让一个 no-ref point/box 在两个不同的同类区域间切换。两条都保留且同 optimizer update；只做 NTP，没有独立配对损失。

训练前统一源图 SHA/SA 身份，排除 benchmark、旧开发集和 pilot 留出；新 dev/test 额外排除 pilot train。独立审计读取 80,309 个图片路径，检查 20,781 个池/合板别名，并保守隔离 dHash≤6 候选。近似哈希相近不等于已经证明同一张图；原始审计证据保留。当前检查未发现剩余跨 split 冲突；不声称排除了基座预训练泄漏。

物化后再按公开输入检查答案冲突，并成对隔离。curriculum 检查每条上下文、ID 和监督后缀，与原生图像 processor 抽样对照。8192 上限内实际最大 2712 tokens。末尾不足 batch 保留真实样本，padding loss 为 0。

## 5. 实际覆盖缺口

完整主集 <1% 面积目标占 60.94%，<0.05% 仅占 0.458%。小目标已经重采样，但极小区域受缓存范围及 RT 门槛限制，不能用重复少量来源凑配额。

带 site、标签回退到 host 的 add 子集只允许 noref-box/ref-mask/noref-mask；主集该子集 34,581 个目标，其中 34,089 为 mask-copy、492 为 box，text/point 为 0。主训练未知目标中 add 仅 4.50%。这些是避免含糊标签时引入的实际覆盖代价，需要审计语义后再扩展模式。

主训练 RT≥0.7，而本次 benchmark 72 个独立目标中有 20 个 GT→codec→decode IoU<0.7。降低教师质量阈值、增加 add 比例、扩展语义反事实属于待验证改进；它们未被追溯加入本轮结果。详细证据见 [问题分析](pass1_analysis.md)。

固定配方是 [formal_data.json](../configs/pass1/formal_data.json)，重建顺序和完整命令见 [运行与复现](pass1_reproduction.md)。

## 1. 所有实验共用的设定

| 项 | 设定 |
|---|---|
| 底座 | Qwen-Image-2.1：MMDiT 和 VAE **冻结** |
| 文本编码器 | Qwen3-VL-8B-SAMTok（词表里有 mask token），**冻结** |
| 训练的部件 | ① DiT LoRA：秩 32，加在 DiT 的全部线性层上（DiffSynth 自动检测的范围），新初始化，所有卡同步；② 码本向量注入：SAMTok 码本向量经 3 个零初始化的线性投影，加到 ⟨M⟩ 位置的文本编码器输出上；③ 路由 logit 的校准：每层 2 个标量。三者合计约 8,700 万个参数 |
| 推理时的输入 | 源图 + 指令，指令里的 ⟨M⟩ 紧跟 "the selected region"（no-ref）或 ref 短语。**不给像素 mask，不加注意力偏置，不做融合** |
| 训练设置 | 学习率 1e-4，预热约 2.5%，batch 32，最大 1 MP（短边对齐 32），所有卡初始化一致（v3 代码已修正） |
| 算力估计 | 本机 8 卡约每小时 4,400 条样本（按 E-A2 实测）；四机约 4 倍 |

## 3. 实验

### P0 准备（不训练）

1. D4 转换成协议 2.0。
2. 划分开发集。
3. 编写训练行构建器：
   - 指认行：从 D2 采样单 token 和多 token，生成目标图和反例；
   - 编辑行：从 D1、D3、D4 生成，并在线拼合 D5。
4. 编写编辑评测脚本：
   - 执行区域外的保持程度；
   - 区域内与教师目标图的接近程度；
   - remove 换 token 探针；
   - 按面积分组的指认 IoU；
   - 多 token 全部涂对的比例。
5. **基线 C0**：原版、E-A2 在新开发集上各跑一次。

- **耗时**：编码约 1 天，GPU 约 2 小时（含 D2 的约 8.5 万个 mask 用 SAMTok 编码，8 卡约 15 分钟）。

### C1 阶段 A'：学定位

| 项 | 内容 |
|---|---|
| 起训权重 | 原版 Qwen-Image-2.1，新的 LoRA、码本注入和路由校准 |
| 任务 | **指认 85%**："Apply a &lt;颜色&gt; semi-transparent mask to the selected region ⟨M⟩ and keep everything else unchanged."，目标图 = 源图 + 该区域 50% 着色。单 token 占 65%，多 token（2–5 个，每个一种颜色，一句话列出）占 35%；用 D2 的类别名生成 ref 写法，占三成。**编辑 15%**：D1 的 no-ref 带 token 行，避免 LoRA 只会着色 |
| 数据 | D2 去掉开发集源图后的约 8 万个 mask。按 benchmark 的面积分布采样，小于 0.5% 的约占 45% |
| 方法 | ① FM 损失 + 区域内误差按面积归一后加权；② 同图其他 mask 处的误差加权，**包括包含关系的部件和宿主**（例如袖子对外套）；③ "写"方向路由：区域内的图像 token 对自己的 ⟨M⟩ 注意力更高，同图其他实例和句中其他 ⟨M⟩ 的区域作反例；④ **"读"方向路由（新）**：⟨M⟩ 对源图 token 的注意力集中在区域内；⑤ 码本向量注入 |
| 规模 | 2,000 次更新 × 32 = **6.4 万条样本** |
| 耗时 | 实现约 1 天；训练本机约 15 小时（四机约 4 小时）；评测约 1 小时 |
| 放行线（开发集，暂定） | 单 token 指认 IoU ≥ 0.65；面积小于 0.5% 的区域 ≥ 0.45；多 token 全部涂对的图 ≥ 50%；换 token 成对跟随 ≥ 0.75 |

### C2 阶段 B：学编辑

| 项 | 内容 |
|---|---|
| 起训权重 | C1 的 LoRA、码本注入和路由校准 |
| 任务与配比 | **单条编辑 65%**：D1 50%、D3 15%。写法上，no-ref 带 token 65%，ref 带 token 20%，ref 不带 token 15%。**多目标编辑 10%**：D4 和 D5，每个目标一句 no-ref 加自己的 token，顺序随机打乱。**指认 15%**：来自 D2，防止忘掉定位。**不再使用程序化编辑** |
| 方法 | ① 特权自蒸馏：D1 的目标图是原版模型拿着区域、局部放大后做出的编辑，学生只看 token 和整图；② FM 损失 + 执行区域内误差按面积归一加权；D1 用 `support_mask`，D3、D4 用执行区域或编辑区域；③ 执行区域外贴边一圈加权（紧邻保护）；④ 同图其他实例处加权；⑤ 双向路由，标签取执行区域（add 是附着处周围）；⑥ 训练时以 10% 的概率去掉 token，为推理时的 token 引导做准备；⑦ 多目标时每个目标的区域损失分别归一后相加 |
| 规模 | 2,500 次更新 × 32 = **8 万条样本** |
| 耗时 | 训练本机约 18 小时（四机约 5 小时）；评测约 2 小时 |
| 放行线（开发集，暂定） | 每类编辑不低于"原版 + ref 文字"；remove 换 token 成对跟随 ≥ 0.7；remove 区域内纹理不低于源图同区的 0.85；执行区域外改动不高于原版的一半；多目标全部完成的比例高于逐条顺序执行 |

## 5. 下一步：P0 + C0 + C1 的详细设计（2026-10-16）

### 5.1 P0：数据准备

1. **划分开发集**：见第 2 节。
2. **指认用的 mask 池**（D2，只取训练源图）：
   - 保留面积占图 0.05%–30% 的 mask，约 7.3 万个；更小的 SAMTok 和 DiT 都分辨不出，更大的多是天空、地面一类背景。
   - 用 SAMTok 编码成 token，8 卡约 20 分钟。
   - 记录每个 mask 的类别名（取 `category` 的最后一个词）、面积、所在源图。
   - 记录同图 mask 之间的关系：
     - 同类：类别名相同；
     - 部件和宿主：A 的 90% 以上落在 B 里，且 B 至少是 A 的 2 倍大；
     - 互不重叠。
3. **训练行**：
   - 指认行：目标图由程序生成，即源图上对应区域叠 50% 的颜色；
   - 编辑行：取 D1 训练部分的盲指代句子，带上 `support_mask` 和 `edited_region`。
4. **评测集**（全部取自开发集的 60 张图）：
   - 单 token 指认 600 个区域：不带物体名 400、带物体名 200，面积分布按 benchmark 抽样；
   - 多 token 指认 100 句：每句 2–4 个 token；
   - 换 token 成对 200 对：同一句话、两个区域，其中"部件对宿主"50 对；
   - 编辑 100 条：四类各 25；
   - remove 探针 60 对。

   在 8 卡上推理一遍约 40 分钟。

### 5.2 C0：基线

- **模型**：原版、E-A2。
- **评测**：在 5.1 的开发评测集上各跑一遍，约 1.5 小时。
- **说明**：E-A2 训练时用的写法是 "this region ⟨M⟩"，在新写法下的表现作为参考，不算正式对照。

### 5.3 C1：阶段 A'，学定位

**目的**：让 DiT 只凭 prompt 里的 mask token 找到区域，重点是小区域、多个 token 同时出现，以及部件和宿主的区分。

| 项 | 设定 |
|---|---|
| 起训权重 | 原版 Qwen-Image-2.1；新的 LoRA（秩 32，DiT 全部线性层），码本注入的投影零初始化，路由校准从 (1, 0) 开始；所有卡初始化一致 |
| 冻结 | DiT 原权重、VAE、文本编码器 Qwen3-VL-8B-SAMTok |
| 规模 | 2,000 次更新 × batch 32 = 64,000 条样本（8 卡 × 每卡累积 4 条）。指认 54,400 条、编辑 9,600 条 |
| 超参 | 学习率 1e-4，前 50 步线性预热，之后不变（与 E-A2 相同，便于对照）；最大 1 MP；路由层 6/10/14/18/22/26；每 500 次更新存一次权重，并在 160 条开发样本上快速评测 |
| 耗时 | 本机 8 卡约 15 小时；四机约 4 小时 |

**训练行（每 100 条）**：

| 类型 | 条数 | 写法（示例） | 目标图 |
|---|---:|---|---|
| 单 token、不带物体名 | 40 | `Apply a red semi-transparent mask to the selected region ⟨M⟩ and keep everything else unchanged.`（4 种句式轮换，颜色随机） | 源图 + 该区域 50% 着色 |
| 单 token、带物体名 | 15 | `Apply a red semi-transparent mask to the chair ⟨M⟩ and keep everything else unchanged.` | 同上 |
| 多 token（2–5 个） | 30 | `Apply semi-transparent masks: red to the selected region ⟨M1⟩, blue to the selected region ⟨M2⟩ and green to the selected region ⟨M3⟩. Keep everything else unchanged.` | 各区域分别着各自的颜色 |
| 编辑（D1） | 15 | `Remove the selected region ⟨M⟩.` 等盲指代句子 | D1 的目标图 |

**指认区域的选取**：
- **面积**：按 benchmark 的分布抽样。各段占比为：<0.1% 5%，0.1–0.25% 20%，0.25–0.5% 20%，0.5–1% 20%，1–2% 15%，2–5% 12%，≥5% 8%。
- **同图实例**：约一半的指认行要求同一张图里另有同类实例，或有部件与宿主的关系，作为反例来源。
- **多 token 行**：选互不重叠的区域；颜色从 6 种高区分度的颜色里选，避开该区域原本的颜色。

**损失**：
1. **FM 损失**：整图的流匹配损失。
2. **区域内误差**：编辑行按 `support_mask` 面积归一后加权；指认行按各自区域的面积归一，多 token 时每个区域分别归一再相加。权重 1。
3. **反例区域的误差**：同图其他 mask，**包括部件对宿主**（宿主除部件以外的部分），这些地方输出必须不变。权重 1。
4. **写方向路由**：在 6 个路由层上，区域内的目标图像 token 对自己的 ⟨M⟩ 的注意力要高于区域外的 token。反例包括同图其他实例、宿主或部件，以及句中其他 ⟨M⟩ 的区域。正例和反例各占一半权重，系数 0.05。编辑行的正例区域取源 mask ∪ `edited_region`。
5. **读方向路由（新增）**：⟨M⟩ 的 4 个 token 对**源图** token 的注意力，要集中在它自己的区域内（与区域内均匀分布做 KL 散度），系数 0.05。源图在整个采样过程中都是干净的，所以每个时间步都能稳定监督。
6. **码本向量注入**：同 E-A2。

**评测与放行线**（开发集）：

| 指标 | 放行线 | 参考（E-A2，旧评测集） |
|---|---|---|
| 单 token 指认 IoU（不带物体名） | ≥ 0.65 | 0.61 |
| 其中面积 < 0.5% 的区域 | ≥ 0.45 | 0.12–0.28 |
| 多 token：所有区域都涂对的句子 | ≥ 50%，颜色涂错位置的比例 ≤ 10% | 未训练过 |
| 换 token 成对跟随 | ≥ 0.75；部件对宿主 ≥ 0.6 | 0.74 |
| 编辑行（检查有没有副作用） | support 外的改动不高于原版；remove 探针成对跟随 ≥ 0.5 | — |

**之后怎么走**：
- 过线：用 C1 的权重进入 C2。
- 只是小区域没过：先试一次"训练分辨率提高到 1.5 MP"或"提高小区域的采样比例"，各 600 次更新、约 4.5 小时，再决定。
- 多 token 没过：检查路由里句中其他 ⟨M⟩ 的反例是否生效。

**代码改动**（约 1–1.5 天，含测试和冒烟运行）：
- mask 池和关系索引、指认行与多 token 行的构建；
- 训练器：
  - 多个 span 各自的写方向路由；
  - 读方向路由；
  - 编辑行用 `support_mask` 和 `edited_region`；
  - 新数据格式的读取，包括 PNG 和 RLE 两种 mask；
- 评测：
  - 多颜色读回；
  - 换 token 成对；
  - 编辑指标；
  - remove 探针（改用盲指代写法）。

## 7. C1b：补上近邻硬反例（2026-10-17）

**设置。**
- 起训：C1 第 1,500 次的权重。LoRA、码注入、写和读两个方向的路由校准都接上。

1. **反例按距离取，不分类别。**

3. **多 token 行。** 40% 围绕一对相邻区域组成（C1 中含相邻同类对的只有 13%）。
4. **编辑行。** 编辑 token 解码区域附近的标注物体作为反例，排除被编辑物体本身和它的部件；96.7% 的编辑行有反例。

**评测。** 用与 C1 相同的 1,320 项开发集，和 C1 第 1,500 次配对比较。

**这次要看的。** 放行线不变，本轮的目标是：
- 近邻失误占失败的比例从 34% 降到 20% 以下；
- 单 token IoU 超过 0.5；
- 部件对宿主的跟随超过 0.5；

## 8. 诊断：训练后定位是否提升，编辑是否受损（2026-10-17）

**目录与对象。**
- 目录 `V3/diag_20261017/`：脚本在 `scripts/`，结果文件见各小节。
- 比较对象：
  - 原版：原版 DiT + SAMTok 文本编码器，也就是我们管线里的原版；
  - C1：C1 第 1,500 次；
  - C1b：C1b 第 800 次；
  - 官方原版：官方文本编码器，用来区分"换编码器"和"训练"各自的影响。

### 8.1 定位：明显提升，而且确实靠 token

**行为**（开发集 1,320 项，`progression.txt`）。单 token 指认 IoU：原版 0.105 → E-A2 0.278 → C1 0.405 → C1b 0.428。

**机制**（`probe/`、`probe_summary.txt`、`attention_cases.jpg`）。
- 方法：
  - 在 400 个单 token、不带物体名的指认上，按正式评测的设置做真实推理（20 步），在 DiT 每一层记录两种注意力：
    - 读：token 对原图各位置的注意力，每个头在原图 token 上做 softmax 后取平均；
    - 写：目标图各位置对 token 的注意力 logit。
  - 再用同一句话、去掉 token 生成一次作对照，每隔一项做一次。

| 指标 | 原版 | C1b |
|---|---:|---:|
| 读：区分目标与其余区域的 AUROC（最好的一层） | 0.74（第 20 层） | **0.92**（第 14 层） |
| 读：区分目标与相邻物体的 AUROC | 0.69 | 0.86 |
| 读：注意力最高点落在目标内（最好的一层） | 3% | 27% |
| 写：第 0 步区分目标与其余区域的 AUROC（最好的一层） | 0.71 | **0.97** |
| 写：第 10 步区分目标与相邻物体的 AUROC | 0.65 | 0.89 |
| 去掉 token：输出与有 token 时的重合度（IoU） | 0.34 | **0.06** |
| 去掉 token：仍落在目标附近 | 42% | 16% |

**结论。**
- 训练前，原版 DiT 从 SAMTok token 里只能读到很弱的位置信息。它的输出主要跟着"哪个东西显眼"走，与不给 token 时有三分之一重合。
- 训练后，token 的读、写两侧注意力都集中到了目标上。输出由 token 决定，去掉 token 后几乎换了一个地方涂。

**剩余的近邻失误**（C1b 的 120 个）：
- 28% 在读的阶段就偏向了邻居；
- 72% 读对了。生成时，第 0 步仍有 71% 偏向目标，到第 10 步降到 55%。

也就是说，一部分在读 token 时就分不清，更多的是在去噪过程中，随着画面成形被旁边的物体"吸走"。

### 8.4 更正与补充（2026-10-18）

**几乎没改的比例，扣除区域外漂移后**（开发集 100 个编辑；判为没改：区域内改动减区域外改动 < 5）。

**改动是"上色"还是"改内容"**（`scripts/tint.py`）。
- 方法：在 Lab 空间，把变化明显的像素（ΔE > 12）分成两类：
  - 颜色类：局部纹理保留、色度变化大于亮度变化，像套了一层色；

| add（扣除区域外漂移） | 0.020 | 0.021 | 0.048 |

- add 区域内的改动，原版和 C1b 都约一半是颜色类，教师只有 7%。
- 输出中像调色板半透明覆盖的像素没有增加：区域内 0.131 → 0.096，区域外 0.0058 → 0.0030。

**结论（替代 §8.2 的第 3 点和 §8.3 的原因分析）。**
1. **没有"学会涂色、不会编辑"。**
   - 带 token 时，C1b 的执行率和改动强度都比原版高：没改的比例 63% → 45%，强度翻倍。
   - remove、replace 的结构性改动增加到原版的两倍以上，区域外改动降到三分之一。
   - 编辑输出里也没有出现半透明覆盖。
2. **退化主要在不带 token 时。** 纯文字下 add 变差，模型不知道放在哪，于是不加，或者加好几个。按用户的方法设计，这一场景不需要保持。
